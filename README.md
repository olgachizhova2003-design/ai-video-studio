# AI Video Studio · онлайн-студия для двоих

Закрытое веб-приложение с AI-режиссёром, библиотекой инструкций, референсами и отправкой запросов в API видеогенерации. Оливковый, пудрово-розовый и сливочный интерфейс сохранён из локальной студии.

## Как это работает

- **GitHub** хранит код. Пользовательских данных и настоящих ключей в репозитории нет.
- **Render Free** запускает сервер и выдаёт HTTPS-ссылку. Браузер обращается к своему серверу, а сервер — к ElysiumAI, Higgsfield API, Atlas Cloud или NanoAPI. Браузерный CORS видеосервисов этому пути не мешает; доступность самого API, ключ и баланс всё равно проверяет провайдер.
- **Supabase Free** хранит аккаунты, настройки, зашифрованные API-ключи, общую библиотеку, историю и файлы. Перезапуск Render не удаляет эти данные.

Вход доступен одному или двум email из списка `STUDIO_ALLOWED_EMAILS`. Профили моделей, документы, референсы и сохранённая история общие. Ключи сервисов, настройки подключений и рабочие черновики отдельные для каждой участницы. Проверку статуса задания запускает участница, которая его отправила, со своим ключом. Для обновления общих данных есть кнопка «Обновить».

Под каждым подключением есть проверка: «Идёт подключение» мигает во время запроса; ответ показывает подключение или полученную ошибку. Проверка не запускает видеогенерацию. Prompt AI при подготовке промпта может списывать средства по тарифу своего API. Перед отправкой видео показывается запрос и требуется подтверждение.

## Бесплатный запуск

Нужны аккаунты GitHub, Supabase и Render. Выбирайте Free на обоих хостингах. Платная подписка на сайт Higgsfield не заменяет его отдельный API-ключ и API-баланс.

### 1. Создайте Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard), создайте организацию на Free и проект `ai-video-studio`. Сохраните пароль базы в своём менеджере паролей; приложению он не нужен.
2. В **SQL Editor → New query** вставьте весь файл [supabase.sql](supabase.sql) и нажмите **Run**. Он создаст таблицу и закрытое хранилище `studio-media`.
3. В **Authentication → Users → Add user → Create new user** создайте два аккаунта: ваш email и email подруги, каждый со своим паролем. Включите **Auto Confirm User**, чтобы можно было войти сразу. Если переключатель отсутствует, подтвердите адреса штатным способом в Supabase. Пароли используйте только для входа в студию.
4. В настройках **Authentication** отключите **Allow new users to sign up**. В некоторых версиях панели этот пункт находится в **Sign In / Providers → Email**. Email/password должен оставаться включённым; публичная регистрация студии не нужна.
5. В **Project Settings → API Keys** найдите **Publishable key** (`sb_publishable_…`) и существующий **Secret key** (`sb_secret_…`, кнопка Reveal API key). Приложение поддерживает новые ключи и прежние legacy `anon`/`service_role` (`eyJ…`). Предпочтительны новые: панель Supabase предупреждает о прекращении поддержки legacy в начале 2027 года. Адрес **Project URL** вида `https://xxxx.supabase.co` есть в **Connect** или настройках **Data API**.

Secret key (или legacy `service_role`) открывает серверу доступ к данным. Вставляйте его только в настройки Render из следующего шага. Не публикуйте ключи в GitHub, переписке или скриншотах.

### 2. Подключите Render

Самый короткий путь — [создать Blueprint из этого репозитория](https://render.com/deploy?repo=https://github.com/olgachizhova2003-design/ai-video-studio). Если ссылка не открывает настройку, зайдите в [Render Dashboard](https://dashboard.render.com), выберите **New → Blueprint**, подключите GitHub и репозиторий `olgachizhova2003-design/ai-video-studio`, ветку `main`.

Render прочитает [render.yaml](render.yaml). Проверьте **plan: Free** и заполните запрошенные поля:

| Поле | Что вставить |
| --- | --- |
| `SUPABASE_URL` | Project URL из Supabase, без `/rest/v1` |
| `SUPABASE_ANON_KEY` | Publishable key того же проекта (либо legacy `anon`) |
| `SUPABASE_SERVICE_ROLE_KEY` | Secret key того же проекта (либо legacy `service_role`) |
| `STUDIO_ALLOWED_EMAILS` | Два email созданных аккаунтов через запятую |

`APP_SECRET` и `STUDIO_MASTER_KEY` Blueprint сгенерирует сам. Не меняйте `STUDIO_MASTER_KEY` после сохранения ключей: без прежнего значения их нельзя расшифровать. Сохраните оба значения в своём менеджере паролей на случай переноса приложения.

Нажмите создание/развёртывание Blueprint. В этой конфигурации создаётся только один бесплатный Web Service, без базы Render и без платного диска. Дождитесь статуса **Live**. Адрес будет вида `https://ai-video-studio-xxxx.onrender.com`; точный адрес покажет Render.

Если создаёте **New → Web Service** вручную: Python runtime, Free, Build `pip install -r requirements.txt`, Start `gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 180 wsgi:app`, Health Check `/healthz`. Кроме четырёх полей выше добавьте два разных случайных секрета длиной от 32 символов: `APP_SECRET` и `STUDIO_MASTER_KEY`. Используйте генератор паролей; не берите значения из `.env.example`.

### 3. Откройте студию вместе

1. Откройте выданную Render HTTPS-ссылку. Войдите с аккаунтом из Supabase Auth.
2. В «Подключениях» добавьте собственные ключи: для Prompt AI — Base URL, API-ключ и точный ID модели; для Higgsfield — API Key ID и API Key Secret. Эти поля не заполняются ключами Supabase.
3. Сохраните настройки, загрузите список моделей и нажмите «Проверить подключение» под нужным сервисом. Приложение покажет полученную ошибку, если API не принял запрос.
4. Отправьте подруге ту же ссылку. Она входит своим email и паролем и добавляет свои API-ключи. Для доступа к студии ей не нужен GitHub или Render.

Ключи из прежней локальной студии автоматически на сайт не переносятся. Добавьте их один раз на сайте: после этого они сохраняются в Supabase в зашифрованном виде.

## Ограничения бесплатного варианта

По условиям сервисов, проверенным 21 ноября 2026:

- Render Free засыпает после 15 минут без входящих запросов. Первый заход после сна может открываться около минуты. На workspace доступно 750 бесплатных часов работы web-сервисов в месяц; учитываются также ограничения трафика и сборок. При исчерпании лимитов сервис может приостановиться.
- Supabase Free: база 500 MB, файловое хранилище 1 GB, исходящий трафик 5 GB и отдельно 5 GB cached egress. После недели неактивности проект может приостановиться — его нужно восстановить в панели.
- Лимит одного загружаемого референса в этой сборке — 25 MB. Удаляйте ненужные референсы; важные результаты видео скачивайте из истории на свой компьютер. Ссылки на результаты у провайдеров могут истекать; приложение не архивирует их видео автоматически в Supabase.
- Бесплатен выбранный хостинг в пределах его лимитов. Использование AI и генерация видео оплачиваются отдельно вашему провайдеру. Постоянная доступность без пауз на бесплатных тарифах не гарантируется.

Актуальные условия: [Render Free](https://render.com/docs/free), [Supabase Pricing](https://supabase.com/pricing).

## Если что-то не открывается

| Проблема | Что проверить |
| --- | --- |
| Render не запустился | Вкладку Logs. Все переменные должны быть заполнены; `APP_SECRET` и `STUDIO_MASTER_KEY` — от 32 символов. |
| `Invalid login credentials` | Email и пароль именно пользователя **Authentication → Users**, а не пароль базы или аккаунта Render. |
| Email не подтверждён | Подтвердите email пользователя в Supabase Auth. |
| HTTP 401/403 от Supabase | Publishable/anon и secret/service_role должны быть ключами одного проекта; привилегированный ключ должен находиться в `SUPABASE_SERVICE_ROLE_KEY`. |
| Нет таблицы или bucket | Выполните `supabase.sql` в том же проекте. |
| Supabase недоступен | Проверьте, активен ли Free-проект и нет ли паузы после неактивности. |
| Ошибка подключения AI | Смотрите полный текст ошибки в «Подключениях»: адрес, модель, баланс, доступ к API и ключ проверяются отдельно. Сервер устраняет браузерный CORS, но не меняет правила провайдера. |

## Разработка и проверка

Python 3.13; зависимости в [requirements.txt](requirements.txt). На Windows Gunicorn не запускается — он предназначен для Render/Linux. Автотесты работают и на Windows.

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s . -p 'test_*.py' -v
node --check static/app.js
node --check static/login.js
node --check static/online.js
```

Проверки используют подменный Supabase и не запускают платные генерации. Реальная приёмка после настройки: вход двумя аккаунтами, проверка AI-подключений, сохранение данных после перезапуска Render, общая библиотека и отдельные ключи. Живые интеграции можно проверить только после указания ваших настроек и аккаунтов.

`engine.py` содержит общее ядро локальной студии; онлайн-приложение запускается через `wsgi.py`, а `app.py` подключает облачное хранение и авторизацию. Локальные SQLite/DPAPI-механизмы ядра онлайн-запуском не используются. Шрифты поставляются вместе с их SIL Open Font License.
